# 看取り勉強会 スライド

ケアマネジャー向け 60分講義用のHTMLスライド（全44枚）。

## 使い方

`mitori-lecture.html` をブラウザで開くだけです。外部ファイル・ネット接続は不要（1ファイル完結）。

### キーボード操作

| キー | 動作 |
|---|---|
| `→` `←` / `Space` / `PageDown` `PageUp` | 前後のスライドへ |
| `Home` / `End` | 最初 / 最後へ |
| `O` | 目次を開く（クリックでジャンプ） |
| `S` | 進行メモの表示切替（各スライドの話し方のポイント） |
| `T` | 配色の切替（ライト / ダーク） |
| `F` | 全画面 |
| `P` | 印刷 → PDF書き出し |

画面のクリック／タップ・スワイプでも移動できます。URLの `#12` のように番号を付けると、その枚数から開けます。

### PDFにする

`P` を押して、印刷ダイアログで **用紙: 横向き / 余白: なし / 背景のグラフィック: オン** を選び「PDFに保存」。1スライド＝1ページで書き出されます。

## 構成

| 章 | 枚数 | 内容 |
|---|---|---|
| 導入 | 1–3 | 今日の問い・目次 |
| 第1章 いま何が起きているか | 4–11 | 多死社会・死亡場所の変化・病院・支え手・資源 |
| 第2章 決まっていない、しかし避けているのではない | 12–22 | ACP認知度・**62.8% vs 2.1%**・共有の断絶・切り出す抵抗53.2%・国際比較 |
| 第3章 型を渡す | 23–28 | 切り出しの型3つ・担わないことの明示・台湾型・4つの問い・未決リスト |
| 第4章 場所と、夜 | 29–42 | 揺れる希望・自宅を諦める理由・5つのゲート・夜の119番・予告シート・遺族評価 |
| おわりに | 43–44 | 空席の話・明日からの1つ |

講義の中核は **15枚目**（話し合っていない理由：「きっかけがなかった」62.8% ／「話し合いたくない」2.1%）です。ここに時間を厚く配分する前提で組んでいます。

## 出典

厚生労働省「令和4年度 人生の最終段階における医療・ケアに関する意識調査」「人口動態統計」「患者調査」「病床機能報告」、国立社会保障・人口問題研究所「日本の世帯数の将来推計（令和6年推計）」、森川岳大「終末期の医療・ケアに関する制度的枠組みの国際比較」（2020）、Detering KM et al. BMJ 2010 ほか。各スライド下部に個別に明記しています。

## デザイン

- 配色は 藍 `#2F62B0` / 朱 `#C2452A` / 青緑 `#12866F`。朱は「核心・崩壊点・自宅」にのみ使用。
  ライト・ダーク両モードで、明度帯・彩度・色覚多様性(CVD)分離・コントラストを検証済み。
- 見出しは明朝体、本文はゴシック体、数値は等幅（桁揃え）。いずれもOS標準フォントを使用。
- スライドは1280×720固定。ウィンドウサイズに合わせて自動で拡大縮小します。
