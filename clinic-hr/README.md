# クリニック人事評価システム

クリニック（診療所）向けの人事評価システムのプロトタイプです。サーバー・ビルド不要で、ブラウザだけで動作します（データは `localStorage` に保存）。

## 使い方

`clinic-hr/index.html` をブラウザで開くだけです。

```
# ローカルで動かす例
cd clinic-hr
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

※ ES Modules を使うため、`file://` で直接開くとブラウザによっては読み込めません。上記のように簡易サーバー経由での起動を推奨します。

## 主な機能

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | 評価進捗・平均スコア・ランク分布・職種別平均・要フォロー人数 |
| 職員 | 職員の登録／編集／削除、職種・部署・勤続年数の管理 |
| 評価入力 | 自己評価 / 1次評価 / 2次評価を業績・能力・情意の3軸で入力、合成結果を即時表示 |
| 目標管理(MBO) | 期ごとの目標設定と進捗管理（総合スコアの20%に反映） |
| 評価項目設定 | 職種別の評価項目・カテゴリ・ウェイトを編集（既定に戻す機能あり） |
| レポート | 期の結果をスコア降順で集計、CSV出力・印刷/PDF |
| 設定 | 評価期間の追加/締め、評価者ウェイト、ランク閾値、データのエクスポート/インポート/初期化 |

## 評価ロジック

- 各評価項目は **5段階**（5:期待を大きく上回る 〜 1:著しく不足）。
- 評価者ごとに項目ウェイトで加重平均し、5点満点を **%** に換算。
- 自己 / 1次 / 2次 を既定ウェイト（**20% / 50% / 30%**）で合成。
- 目標(MBO)達成度を総合の **20%**、評価合成を **80%** として総合スコアを算出。
- 総合スコアからランク（既定：**S≥90 / A≥80 / B≥70 / C≥60 / D**）を判定。

ウェイトや閾値は「設定」画面から変更できます。

## 職種マスタ（初期値）

医師 / 看護師 / 准看護師 / 医療事務 / 受付 / 臨床検査技師 / 診療放射線技師 / 理学療法士

接遇・医療安全・守秘義務などの共通項目に加え、職種別の専門項目（看護技術、レセプト精度、検査精度 等）を初期搭載しています。

## ファイル構成

- `index.html` — 画面シェル
- `app.css` — スタイル
- `app.js` — アプリ本体（状態管理・スコア計算・各画面）
- `data.js` — 職種・評価項目テンプレート・初期データ
