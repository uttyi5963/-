# クリスタルナイツ 〜あんこくきしの ものがたり〜

ゲームボーイ風・FF4ライクの ATBバトルRPG。ビルド不要、ブラウザだけで動きます。

![ジャンル](https://img.shields.io/badge/genre-JRPG-306230) ![依存](https://img.shields.io/badge/deps-none-8bac0f)

## あそびかた

```bash
cd rpg
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` をダブルクリックで直接開いても動作します(セーブはlocalStorage)。

## そうさ

| キー | はたらき |
|---|---|
| 矢印キー / WASD | いどう・カーソル |
| Z / Enter / Space | けってい・はなす・しらべる (Aボタン) |
| X / Esc | キャンセル・メニュー (Bボタン) |
| M | サウンド ON/OFF |

スマホ・タブレットでは画面上の十字キーとA/Bボタンで操作できます。

## システム (FF4リスペクト+独自アレンジ)

- **本格ATB (ウェイト/アクティブ)** — ニューゲーム時に選択、メニューの「せってい」でいつでも切替。ウェイトはコマンド入力中に時間が完全停止、アクティブは敵が待たない上級者向け。魔法は詠唱時間つき(敵の大技は詠唱が見える)
- **5人パーティ+前後列** — 後列は物理ダメージ与/被半減。「たいれつ」で並び替え
- **キャラ固有コマンド** — あんこく(HP消費全体攻撃)、ジャンプ(使うたびダブルジャンプに進化)、ためる(最大3回で2/4/8倍)、かばう(身代わりダメージ一桁+50%カウンター)、いのる(全員HP30%回復)、せいけん
- **属性システム** — 弱点8倍・耐性0.5倍・吸収(回復される)。竜特効・アンデッド特効も8倍
- **生きのこりボーナス** — 経験値は生存者全員に満額。さらに倒れた仲間1人につき獲得+50%(5人パーティ1人残しで3倍)。あえて1人で戦う集中レベリングができる
- **状態異常** — どく/くらやみ/ちんもく/カエル(姿もカエルに)。エスナ・各種アイテム・宿屋で治療
- **クラスチェンジ** — 試練を乗り越えると暗黒騎士がパラディンに
- **ボス戦ギミック** — 「攻撃してはいけない」試練ボス、2形態のラスボス、属性吸収ボス
- **隠し宝箱** — 足元や壁際を「しらべる」と発見
- セーブ4スロット (localStorage)、討伐/おつかいクエスト
- **パスワード (セーブコード)** — メニューやタイトルの「パスワード」でセーブを文字列に書き出し/読み込み。スマホなど保存が消えやすい環境や機種変更時の引き継ぎに。localStorageが使えない環境でもメモリ保存+パスワードでプレイ可能
- **エリア別バトル背景** — 平原/洞窟/氷/溶岩/塔/神殿/海底で背景が変化。ヒットエフェクトと敵HPバーつき
- **フィールド演出** — 水面の2コマアニメ、草原の花と草むら、歩行バウンス、戦闘突入ブラインド、タイトル画面の雲・山並み・クリスタルの光輪

## ものがたり (第1章: 地上編)

バロン王の命により、ミストの村から「クリスタル」を奪うことになった暗黒騎士レオン。
しかし王の様子はどこかおかしい……。

1. **バロン城** — 王命を受け、親友の竜騎士グレンと出発
2. **にしのどうくつ** — 黒魔道士ロッドが加入、デーモンガードを討伐
3. **ミストのむら** — 長老からクリスタルを託され、白魔道士セリアが加入
4. **こころのほこら** — モンクのゴウが加入。「こころのかがみ」の試練 → パラディンへ
5. **まてんろう** — 魔皇ザルバとの決戦

## ものがたりは全5章+真エンド

1. **第1章 地上編** — 王命と暗黒騎士。試練を越えてパラディンへ、魔天楼でザルバと決戦
2. **第2章 ちていへん** — 大穴の底から地底世界へ。鍛冶の里ムスペル、地底神殿で「ちのクリスタル」
3. **第3章 てんくうへん** — ひこうせん入手。そらのしまの風の神殿で「かぜのクリスタル」
4. **第4章 しんかいへん** — 潜水装置で海の底へ。「みずのクリスタル」で4つが揃う
5. **最終章 ほしのとう** — 真の黒幕ヴォイドスとの決戦、完全版エンディング

### 寄り道・やり込み

- **こおりのどうくつ/ちかすいろ** — フロストドラゴン、クラーケン討伐と報酬クエスト
- **とうぎじょう(ソレイユ)** — 参加費制の3連戦×3ランク。ゴールド制覇でチャンピオンベルト
- **しれんのやま** — 中央山脈の登山口からつづら折りの山道を登り、頂で待つ「けんおうガロン」と拳勝負(報酬: ごうけつのつめ)
- **ドヴェルグおうきゅう** — 地底世界の王宮。バルド王の討伐依頼(マグマトカゲ×5、図鑑連動)でドヴェルグアクス、宝物庫と隠しのたても
- **げんじゅう たいじ** — 4つのクリスタルが揃うと空・地底・海に精霊型レアボスが出現(シルフィド/ノーモス/ウンディナ、EXP8000〜9000)。各固有装備を落とす
- **モンスターずかん** — 全80種。倒すと弱点が開示される
- **ほしのせかい (第2ワールド)** — 4つのクリスタルを集めた後、かぜのしんでんの賢者が空の輪を開く。つきのみやこセレーネと高経験値の狩り場、だいクレーターのぬし「ルナヴォラ」討伐
- **星の世界の後日談** — まいごのステラ捜索チェーン(報酬: ほしのまもり)、真エンド後の吟遊詩人イベント
- **クエストちょう** — 「つぎのもくてき」自動表示+サブクエスト進行管理
- **隠しボス: しんえんりゅう ヴァハ** — 真エンド後、HP9000の最強竜
- **つよくてニューゲーム** — レベル・装備・図鑑を引き継いで2周目へ
- **上位装備2ティア** — つきのみやこセレーネで星ティア装備(atk40〜44)を販売、隠し宝箱に究極装備(ちょうしんせいのつるぎ等atk56〜60)。エクスポーション/ハイエーテル/ばんのうやく追加
- **レベル99まで成長** — Lv15以降も上位魔法を習得: ファイガ/ブリザガ/サンダガ/フレア(黒)、ケアルガ/いやしのあめ(全体回復)/セイントレイ(白)
- 隠し宝箱(足元や壁際を「しらべる」)、せかいのしずく、エリクサー収集

## 技術メモ

- 320x288 Canvas / ゲームボーイ4階調グリーンパレット
- スプライトは全て文字列ドット絵 (`js/sprites.js`)、外部アセットなし
- BGM/SEはWebAudioの矩形波チップチューン (2声・全17曲、すべてオリジナル作曲)
- `js/data.js` にマップ・モンスター・イベントが宣言的に定義されており拡張しやすい構成
