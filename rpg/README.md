# クリスタルナイツ 〜あんこくきしの ものがたり〜

ゲームボーイ風・FF4ライクの ATBバトルRPG。ビルド不要、ブラウザだけで動きます。

![ジャンル](https://img.shields.io/badge/genre-JRPG-306230) ![依存](https://img.shields.io/badge/deps-none-8bac0f)

## あそびかた

```bash
cd rpg
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` をダブルクリックで直接開いても動作します(セーブはlocalStorage)。

## そうさ

| キー | はたらき |
|---|---|
| 矢印キー / WASD | いどう・カーソル |
| Z / Enter / Space | けってい・はなす・しらべる (Aボタン) |
| X / Esc | キャンセル・メニュー (Bボタン) |
| M | サウンド ON/OFF |

スマホ・タブレットでは画面上の十字パッドとA/Bボタンで操作できます。十字パッドはデッドゾーンなしのアナログ式 — パッドのどこを触れても最寄りの方向に反応し、指をスライドさせるだけで方向転換できます。

## システム (FF4リスペクト+独自アレンジ)

- **本格ATB (ウェイト/アクティブ)** — ニューゲーム時に選択、コンフィグでいつでも切替。ウェイトはコマンド入力中に時間が完全停止、アクティブは敵が待たない上級者向け。魔法は詠唱時間つき(敵の大技は詠唱が見える)
- **コンフィグ** — メニューの「せってい」から: 戦闘モード / カーソル記憶(前ターンのコマンド位置を記憶) / 戦闘速度2倍 / 移動速度アップ / エンカウントON・OFF / サウンドON・OFF の6項目
- **5人パーティ+前後列** — 後列は物理ダメージ与/被半減。「たいれつ」で並び替え
- **そうび3わく (ぶき/よろい/アクセサリ)** — アクセサリは全32種: ステータス強化、属性半減/無効、状態異常防止、ひっさつゲージ2倍・MP半減・オートプロテス・かいしん2倍・HP自動回復などの特殊能力。売店/クエスト報酬/隠し宝箱/伝説級(ボスラッシュ報酬)/超高額の5ティア
- **超高額アクセサリ** — セレーネの店の最上段: 英雄の腕輪(350000G、全ステータス+15)と不死鳥の羽飾り(500000G、戦闘中一度だけHP半分で自動復活)。値段は法外、効果は絶大
- **どうぐの連続使用** — メニューでアイテムを使ってもターゲット選択に留まり、在庫があるかぎり続けて使える。全員回復が一気に終わる
- **生命の果実/魔力の果実** — 最大HP+20/最大MP+10が永続する成長アイテム。ドロップ運に頼らず、セレーネの店で堂々と販売(25000G/30000G)
- **きかんのつばさ** — まちやダンジョンから外の世界へ一瞬で脱出する消耗品(各地の道具屋で販売)
- **オートセーブ** — マップを移動するたび自動記録。セーブ/ロード画面の各スロットには現在の章も表示。ロード画面の5枠目「オートセーブ」から再開できる。全滅してもゲームオーバー画面の「つづきから」で直前のオートセーブから即復帰
- **ひっさつわざ (リミット)** — 被弾でゲージが溜まり、100%で「ひっさつ!」コマンド出現。1人3種をレベルで習得(Lv10/30/55帯)。クロスブレイク、りゅうせいらんぶ、ひゃっきれんだ、てんしのきせき、エレメントストームなど全15種
- **キャラ固有コマンド** — あんこく(HP消費全体攻撃)、ジャンプ(使うたびダブルジャンプに進化)、ためる(最大3回で物理2/4/8倍)、かくせい(最大3回で魔法2/4/8倍)、かばう(身代わりダメージ一桁+50%でカウンターせいけん1.6倍)、いのる(75%で全員HP30%回復、Lv30+で時折完全回復・Lv45+で時折蘇生)、せいけん
- **属性システム** — 弱点8倍・耐性0.5倍・吸収(回復される)。竜特効・アンデッド特効も8倍
- **熟練度** — 戦闘で4回行動するごとに+1 (最大99、にげるは除外)。上がると「熟練+1」がポップし、キャラごとに違う能力が伸びる: レオン=HP・力・体力型 / グレン=力・素早型 / ゴウ=力・体力型 / セリア・ロッド=知性・MP型。「強さ」画面で確認できる。ソレイユ闘技場前の師範が熟練度25/50/99の節目に報酬をくれる (10000G+エクスポーション / 果実2種 / 50000G+エリクサー)
- **生きのこりボーナス** — 経験値は生存者全員に満額。さらに倒れた仲間1人につき獲得+50%(5人パーティ1人残しで3倍)。あえて1人で戦う集中レベリングができる
- **状態異常** — どく/くらやみ/ちんもく/カエル(姿もカエルに)。エスナ・各種アイテム・宿屋で治療
- **クラスチェンジ** — 試練を乗り越えると暗黒騎士がパラディンに
- **ボス戦ギミック** — 「攻撃してはいけない」試練ボス、2形態のラスボス、属性吸収ボス
- **隠し宝箱** — 足元や壁際を「しらべる」と発見
- セーブ4スロット (localStorage)、討伐/おつかいクエスト
- **パスワード (セーブコード)** — メニューやタイトルの「パスワード」でセーブを文字列に書き出し/読み込み。スマホなど保存が消えやすい環境や機種変更時の引き継ぎに。localStorageが使えない環境でもメモリ保存+パスワードでプレイ可能
- **エリア別バトル背景** — 平原/洞窟/氷/溶岩/塔/神殿/海底/密林/嵐/夜/砂漠で背景が変化。砂漠はピラミッドとサボテンにかげろう、夜は丘の稜線と大きな星のまたたき+流れ星、氷はオーロラと氷山、嵐は風にしなる木、密林は高さの違う樹々とシダ、溶岩は岩影と立ちのぼる火の粉。ヒットエフェクトと敵HPバーつき
- **属性別の魔法エフェクト** — ほのお(立ちのぼる炎柱)/こおり(咲きわたる結晶)/かみなり(天からのジグザグ稲妻)/せい(降りそそぐ光柱)/クエイク(跳ねる瓦礫)/フレア・メテオ(二重の光輪)。敵の大きさに応じてスケールし、敵の大技にも適用
- **回復・補助・勝利の演出** — ケアル系や回復アイテムはきらめきの十字、蘇生は天からの光柱、プロテスは前方に光の防壁アーク。勝利時は生存メンバーが順番にホップしてきらめきが舞う
- **フィールド演出** — 水面の2コマアニメ、草原の花と草むら、歩行バウンス、戦闘突入ブラインド、タイトル画面の雲・山並み・クリスタルの光輪・ときどき流れ星
- **天候システム** — らいめいのしまは雨、こおりのれっとうは雪、すなのおうこくは砂嵐、緑の群島とリーフェは舞う花びら、夜の国とノクスはまたたく星あかりが屋外マップに降る(マップ範囲にクリップした軽量パーティクル)
- **屋内装飾タイル** — 旗・本棚・石像・燭台・噴水の5種を追加。バロン城玉座の間、長老の家、こころのほこら、地底神殿、ドヴェルグ王宮、大聖堂、町の広場がそれぞれの雰囲気に
- **町の地域色** — 新大陸6町を専用タイルで差別化: 雪原と雪松のフリム、砂丘とヤシのザハラ、花咲く木陰のリーフェ、岩場のボルテ、枯れ木と夜草のノクス、湖畔に花のトワイン (新タイル8種: 砂/雪/雪松/ヤシ/枯れ木/夜草/花/岩地)。地方マップも氷の列島=雪原、砂の王国=砂丘、雷鳴の島=岩場、夜の国=夜草に差し替え。5〜6章ダンジョン10フロアも差別化 (鏡の洞窟=柱の広間 / 氷河の洞窟=氷岩壁+雪床 / 砂の大廟=砂床+瓦礫 / 古代遺跡=苔草+花 / 嵐のほこら=岩がらの床)。星の塔=柱と星くずの床、だいクレーター=岩壁と岩がら、大聖堂2F=じゅうたんの大広間、ほしのはか=夜草の床、海底神殿=水没した壁も差別化
- **出入口の視認性** — すべての出入口(59箇所)に階段/扉タイルを敷き、階段・扉・洞窟アイコンを高コントラストに刷新。「どこから出るのか分からない」を解消

## ものがたり (第1章: 地上編)

バロン王の命により、ミストの村から「クリスタル」を奪うことになった暗黒騎士レオン。
しかし王の様子はどこかおかしい……。

1. **バロン城** — 王命を受け、親友の竜騎士グレンと出発
2. **にしのどうくつ** — 黒魔道士ロッドが加入、デーモンガードを討伐
3. **ミストのむら** — 長老からクリスタルを託され、白魔道士セリアが加入
4. **こころのほこら** — モンクのゴウが加入。「こころのかがみ」の試練 → パラディンへ
5. **まてんろう** — 魔皇ザルバとの決戦

## ものがたりは全7章+真エンド (章タイトルカード演出つき)

1. **第一章 地上編** — 王命と暗黒騎士。試練を越えてパラディンへ、魔天楼でザルバと決戦(章間ロール後そのまま続行)
2. **第二章 地底編** — 大穴の底から地底世界へ。鍛冶の里ムスペル、地底神殿で「地のクリスタル」
3. **第三章 天空編** — 飛行船シリウス号を入手。空の島の風の神殿で「風のクリスタル」
4. **第四章 深海編** — 潜水装置で海の底へ。「水のクリスタル」で4つが揃う——だが星の塔は封印されたまま
5. **第五章 新大陸編** — 世界各地に立ちのぼる災いのもや。東の大陸(鏡のぬし)、氷の列島(氷結の女神)、砂の王国(砂の王)の3つの災いを鎮める
6. **第六章 常夜編** — 緑の群島(守り神)、雷鳴の島(雷神)、そして朝の来ない夜の国へ。悲しみの女王ノクティア(HP16000)を鎮めると星の塔の封印が解ける
7. **第七章 星の塔編** — 3フロア+天層+最上階の最終ダンジョン。天層の回復クリスタルで態勢を整え、真の黒幕ヴォイドスと決戦。完全版エンディングへ

### 寄り道・やり込み

- **とうぎじょう(ソレイユ)** — 参加費制の3連戦×3ランク+地域ボス再戦の「プラチナ」4連戦(報酬30000G)。ゴールド制覇でチャンピオンベルト
- **しれんのやま** — 中央山脈の登山口からつづら折りの山道を登り、頂で待つ「けんおうガロン」と拳勝負(報酬: ごうけつのつめ)
- **ドヴェルグおうきゅう** — 地底世界の王宮。バルド王の討伐依頼(マグマトカゲ×5、図鑑連動)でドヴェルグアクス、宝物庫と隠しのたても
- **げんじゅう たいじ** — 4つのクリスタルが揃うと空・地底・海に精霊型レアボスが出現(シルフィド/ノーモス/ウンディナ、EXP8000〜9000)。各固有装備を落とす
- **モンスターずかん** — 全150種。倒すと弱点が開示され、一度見かけると生息地(エンカウント地域からの逆引き)も表示。北の平原にレアの「おうごんガニ」(8000G)、らいでんのほこらに「ミスリルビ」(EXP8000)
- **ほしのせかい (第2ワールド)** — 4つのクリスタルを集めた後、かぜのしんでんの賢者が空の輪を開く。つきのみやこセレーネと高経験値の狩り場、だいクレーターのぬし「ルナヴォラ」討伐
- **星の世界の後日談** — まいごのステラ捜索チェーン(報酬: ほしのまもり)、真エンド後の吟遊詩人イベント
- **星のかけら あつめ** — 星の塔が開くとセレーネに天文学者が現れる。塔の1〜3階に隠された「星のかけら」3つを集めて報告すると20000G+生命の果実+エリクサー
- **こじんイベント第2章** — 夜の女王鎮圧後、5人それぞれのエピローグ(老騎士とレオン、ガロンとグレンの再稽古、師の幻影とゴウ、シスターとセリア、ガレフ先生とロッド)。各キャラ専用の記念防具つき
- **こじんイベント第3章** — 真エンド後、同じ師たちを再訪すると締めくくりの語らいイベント。各キャラの熟練度+10。クエストちょうに「きわみへの あゆみ (n/5)」で進行表示
- **せかいかいぎ** — 各地の災いを鎮めた後、バロン城の大臣の依頼で4地域の長に招待を届ける横断チェーン。開催式で「きずなのマント」+10000G
- **クエストちょう** — 「つぎのもくてき」自動表示+サブクエスト進行管理。右上に現在の章(第一〜七章)をフラグから逆算して表示
- **ちず (ミニマップ)** — メニューの「ちず」で今いる地方の全体図を表示。現在地が点滅、町やほこらは濃いマーカーで一目瞭然。屋内では最後にいたワールドの地図を表示
- **町の生活感** — 章の進行で台詞が変わる住人が各町に。ミストのむらでは子どもの「かくれんぼ」ミニイベントも
- **そらのふなつきば** — バロン城の南にある飛空艇の整備場。技師長ガレットたちが働き、章の進行で会話が変化(飛空艇には「シリウスごう」の名が)。倉庫のコウモリ退治クエスト(報酬2500G+エクスポーション)
- **みはりのとう** — 中央山脈の西側に立つ2フロアの見張り塔。頂上の「とおめがね」で世界を一望でき、見える景色は物語の進行(飛空艇入手・真エンド)で変化。初回にエリクサー、ものみのワッツのヒントで見つかる隠し1500Gも

- **入れる民家4軒+ねこあつめ** — みならいきし/ねこずき(ミスト)、こうざんふうふ/しゅうしゅうか(ムスペル)の家。世界の5匹の特別なねこを撫でて回る収集クエスト(報酬: ねこのすず)

- **裏ボス: まぼろしのしろ** — 全地域6体のぬしを鎮めると北の空の蜃気楼が実体化。玉座の「まぼろしのおう レガリア」(HP14000/三属性吸収/聖弱点)を倒すと隠し武器「おうのつるぎ レガリア」(atk65・聖・3種族特効)
- **隠しダンジョン: ほしのはか** — ルナヴォラ討伐で封印が解ける迷宮。最深部に最強の隠しボス「ほしぼしのおう グランステラ」(HP12000/EXP50000)、報酬はほしのおうかん
- **でんどうのま** — クリア後にバロン城から入れる実績ホール。全11実績を☆で表示、コンプリートで「えいゆうのあかし」授与
- **けいしょうのま (ボスラッシュ)** — でんどうのまの「けいしょうのばんにん」に挑む連戦モード。ものがたりのみち(章ボス5連戦)→ぬしのみち(地域ぬし6連戦)→しんえんのみち(裏ボス4連戦)と段階開放。幕間にHP40%回復、報酬は最大100000G+せかいのしずく

- **げんかいかいほう** — 上位ジョブ共通の切り札コマンド(1戦闘1回)。5ターンの間、攻撃力と魔力が2倍・ATB1.4倍。効果が切れると2ターンの「つかれ」でATB半減。ステータス欄に「かいN」「つかれ」表示

- **しゅごれい (せいじょ)** — 守護霊を召喚。3ターンの間セリアのターンごとに、いちばん弱った仲間をHP15%自動回復
- **いんようの2式 (おんみょうじ)** — 収束の「いんのしき」(単体大威力)と拡散の「ようのしき」(全体)を交互に撃ち、いん→ようと繋ぐと合成大技「むそうのしき」が発動

- **ごくい (けんせい)** — 昇格したゴウはクリティカルが出るたび連鎖して威力+25%ずつ上昇。外すとリセット
- **トリプルジャンプ (りゅうていきし)** — 昇格したグレンのジャンプは3段目まで進化(1.6倍×3連撃)
