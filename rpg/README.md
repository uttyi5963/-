# クリスタルナイツ 〜あんこくきしの ものがたり〜

ゲームボーイ風・FF4ライクの ATBバトルRPG。ビルド不要、ブラウザだけで動きます。

![ジャンル](https://img.shields.io/badge/genre-JRPG-306230) ![依存](https://img.shields.io/badge/deps-none-8bac0f)

## あそびかた

```bash
cd rpg
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`index.html` をダブルクリックで直接開いても動作します(セーブはlocalStorage)。

## そうさ

| キー | はたらき |
|---|---|
| 矢印キー / WASD | いどう・カーソル |
| Z / Enter / Space | けってい・はなす・しらべる (Aボタン) |
| X / Esc | キャンセル・メニュー (Bボタン) |
| M | サウンド ON/OFF |

スマホ・タブレットでは画面上の十字キーとA/Bボタンで操作できます。

## システム (FF4リスペクト)

- **ATB (アクティブタイムバトル)** — すばやさでゲージがたまり、たまったキャラから行動
- **パーティバトル** — 暗黒騎士レオン、黒魔道士ロッド、白魔道士セリアの最大3人
- **あんこく** — HPを削って敵全体を攻撃する暗黒騎士の専用技
- **クラスチェンジ** — 試練を乗り越えると暗黒騎士がパラディンに(せいけん習得)
- **黒魔法・白魔法** — レベルアップで習得。ファイア/ブリザド/サンダー/ケアル/レイズなど
- **どく・ぼうぎょ・プロテス・にげる**、ぼうぐ/ぶきの装備、ショップ、宿屋
- **ボス戦ギミック** — 「攻撃してはいけない」試練ボス、2形態のラスボス
- セーブ/ロード (localStorage)、ゲームオーバー、エンディング

## ものがたり

バロン王の命により、ミストの村から「クリスタル」を奪うことになった暗黒騎士レオン。
しかし王の様子はどこかおかしい……。西の洞窟を抜け、村の長老が語る真実とは。

1. **バロン城** — 王命を受けて出発
2. **にしのどうくつ** — 黒魔道士ロッドが加入、デーモンガードを討伐
3. **ミストのむら** — 長老からクリスタルを託され、白魔道士セリアが加入
4. **こころのほこら** — 「こころのかがみ」の試練 → パラディンへ
5. **まてんろう** — 魔皇ザルバとの決戦

## 技術メモ

- 320x288 Canvas / ゲームボーイ4階調グリーンパレット
- スプライトは全て文字列ドット絵 (`js/sprites.js`)、外部アセットなし
- BGM/SEはWebAudioの矩形波チップチューン
- `js/data.js` にマップ・モンスター・イベントが宣言的に定義されており拡張しやすい構成
