# 音程チェッカー — バイオリン練習

楽譜を表示し、マイクで拾った演奏音が正しい音程かをカラオケ風にリアルタイム判定するPWA。
クロイツェル等の基礎を「一音ずつ、音程を外さず」弾けるようになるための練習ツール。

- 判定は「めやす」。仕上げは自分の耳と先生の耳で(アプリ内の説明モーダル参照)
- **精度 > 速度**。間違った音を教材化しない。読み取り精度が不確かな楽譜データは内蔵しない

## 使い方(公開)

マイクを使うため **https必須**。`pwa/` フォルダをそのまま [Netlify Drop](https://app.netlify.com/drop) にドラッグして公開し、
iPad の Safari で開いて「ホーム画面に追加」すると全画面のPWAとして動く(2回目以降はオフラインでも起動)。

単一ファイルで済ませたい場合は `index.html` をそのまま配布(SWなし・アイコン等埋込済み)。

## リポジトリ構成

```
violin/
├── src/
│   ├── template.html      HTMLシェル(script本体は /*__INJECT:名前__*/ マーカー)
│   └── app.js             メインスクリプト(判定エンジン・楽譜描画・UI)
├── data/
│   ├── samples.data.js    実録音バイオリンサンプル27個(FluidR3_GM由来、base64)
│   └── pieces.data.js     内蔵曲データ(コンパクト形式)
├── build.mjs              ビルド(依存なし) → index.html と pwa/ を生成
├── test/check.mjs         検証(構文 / ID整合性 / データ健全性)
├── index.html             【生成物】単一ファイル版
└── pwa/                   【生成物】Netlify Drop用(index.html/manifest.json/sw.js/アイコン)
```

`index.html` と `pwa/` はビルド産物だが、そのまま配布できるようコミットしている。
**ソースを編集したら必ず `node build.mjs` を実行してから commit すること。**

## ビルドと検証

```bash
node build.mjs        # index.html と pwa/ を再生成
node test/check.mjs   # 構文 / ID整合性 / サンプル・内蔵曲の健全性チェック
```

SWのキャッシュバージョンは `build.mjs` 先頭の `SW_CACHE_VERSION` で管理。
**アプリを更新したら番号を上げる**(既存ユーザーのキャッシュが入れ替わる)。

## 主な機能

- **課題ソース4種**: 内蔵曲(クロイツェル9番) / MusicXML・MXLファイル / 音階プリセット13種 / 自由入力
- **進み方2モード**: 合ったら次へ(ホールド判定) / メトロノーム(音価から時間枠を計算して自動進行)
- **練習モード2種**:
  - 通し
  - **丁寧(区間マスター)**: 課題を4/8/12音の区間に分け、「✕なし(またはすべて○)を連続1〜3回」達成するまで同じ区間を繰り返す。全区間クリア後に通しで仕上げ
- **苦手音の集中練習**: 結果画面から△✕だった音だけを各3回並べて再練習
- **ドローン**: 開放弦(G/D/A/E)の持続音に重ねて弾き、響きで相対的に音程を確かめる(イヤホン推奨)
- 判定エンジン: ACF2+自己相関(150–2800Hz、中央値平滑化)。厳しさ ○10¢/△25¢(標準)
- ゲーム性: スコア・コンボ・★・自己ベスト(localStorage)
- チューナーモード / 基準ピッチ A=440〜443(デフォルト442)

## 曲の追加ワークフロー

```
IMSLPのきれいな版PDF(1曲分)
  → iOSアプリ「楽譜スキャナー」でスキャン → MusicXML書き出し
  → このアプリの「ファイル」タブで読み込んで動作確認
  → 検証(音域G3–E7内 / 主声部 / 音数 / fifths)
  → data/pieces.data.js のコンパクト形式に変換して追加 → node build.mjs
```

- コンパクト形式: `[step, octave, alter, dur, flags]`。
  flags: `1=小節頭, 2=スラー開始, 4=スラー終了, 8=付点, 16/32/64=連桁begin/continue/end`
- **やってはいけない**: スマホ写真からのOMR(精度が出ない)。精度不足のまま内蔵化しない
- 著作権: クロイツェルはパブリックドメイン。小野アンナ音階教本は2049年まで保護
  (音階そのもののプログラム生成はOK。現行プリセットは生成物)
